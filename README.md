✨ Features

- 🎮 1v1 Game Mode
- 🟢 Easy AI — Random moves
- 🟡 Medium AI — Basic strategy
- 🔴 Impossible AI — Minimax
- 🧠 Best Move Teller
- 🎨 Colorful terminal interface
- 🔢 Simple 1–9 controls
- ⚡ Fast AI calculations

🤖 AI System

🟢 Easy

Random legal moves.

🟡 Medium

Uses basic strategy:

- Winning moves
- Blocking
- Center
- Corners

🔴 Impossible

Uses the Minimax algorithm to evaluate possible future game states and choose an optimal move.

🚀 Installation & Usage

1. Clone the repository

git clone https://github.com/arnavcodex/tic-tac-toe-ai.git

2. Enter the project folder

cd tic-tac-toe-ai

3. Install Colorama

pip install colorama

4. Run the game

python main.py

⚡ Quick Setup

Or run everything directly:

git clone https://github.com/arnavcodex/tic-tac-toe-ai.git
cd tic-tac-toe-ai
pip install colorama
python main.py

🔄 Update the project

If you already cloned the repository:

cd tic-tac-toe-ai
git pull
python main.py
